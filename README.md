# 🐍 NumPy Fundamentals & Numerical Computing

This repository contains my practice scripts, core concepts, and project implementations using **NumPy** (Numerical Python)—the fundamental package for scientific computing in Python.

---

## 📌 Topics Covered

* **Array Basics:** Creating 1D, 2D, and Multi-Dimensional arrays using `np.array()`, `np.zeros()`, `np.ones()`, `np.arange()`, and `np.linspace()`.
* **Array Operations:** Element-wise arithmetic, matrix multiplication (`np.dot`, `@`), broadcasting, and vectorization.
* **Indexing & Slicing:** Boolean masking, fancy indexing, and array reshaping (`reshape()`, `flatten()`, `ravel()`).
* **Random Module (`np.random`):** Generating random distributions, floating values, uniform samples, and probability-based choices (`np.random.choice`).
* **Statistical Functions:** Computing `mean`, `median`, `std`, `var`, `min`, `max`, `sum`, and axis-wise operations.

---
